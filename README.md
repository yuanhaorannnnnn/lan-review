# lan-review

**把文件放在自己的电脑上，让局域网里的团队在内容上直接讨论。**

lan-review 是一个自托管的评审工具。启动服务后，团队成员通过浏览器打开共享列表、上传材料、留下带位置的评论并回复。文件副本和评论保存在托管电脑，无需 Docker 或外部账号。

> 项目仍在开发中。当前面向可信局域网；跨设备和真实触屏验收尚未完成，不适合直接暴露到公网。

## 支持的材料

| 类型 | 评审方式 |
| --- | --- |
| Markdown | 选择文字评论；本地或文件夹导入时可携带相对路径图片 |
| HTML | 在受限预览中选择文字评论；仅运行可信文件 |
| 图片 | 在画面上标点、框选，或尝试智能选物 |
| 视频 | 标记时间点或时间段；也可暂停后标记该帧中的区域 |

图片和视频的智能选物使用本机可选模型，给出轮廓候选，需人工确认。视频的时间段区域对应**起始帧**，不会跟随运动物体。PDF 和跨帧对象跟踪尚未支持。

## 快速开始

托管服务目前仅在 Linux 上验证，需 Python 3.10 或更高版本；Windows 可作为浏览器客户端访问。首次运行，在项目目录执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py
```

浏览器打开终端打印的本机地址，默认是 `http://127.0.0.1:8765/`。选择文件并创建评审；阅读者可选中内容或标记画面，再发表评论。`Ctrl+C` 停止服务。

托管电脑的本机文件选择器需要 Linux 桌面和 `zenity`；不可用时可在页面中输入文件路径。其他设备通过浏览器选择自己的文件。

### 向局域网开放

用托管电脑的实际局域网 IPv4 地址和允许访问的网段启动，例如：

```sh
.venv/bin/python server.py --lan-ip 192.168.1.10 --lan-cidr 192.168.1.0/24
```

把示例中的地址和网段替换成实际网络；Linux 可用 `ip -4 -br addr` 查看本机地址。把终端打印的局域网地址发给团队，成员从该地址打开首页即可。若另一台设备无法访问，还需检查路由、网段和防火墙；本机能打开并不证明跨设备连通。

托管电脑需要保持开机且服务运行。上传后保存的是文件副本，上传者后来修改原文件不会自动同步。

## 使用细节

- **Markdown 图片**：在托管电脑上选择本机文件时，可自动导入引用的本地图片；其他电脑选择“Markdown 与图片一起导入”，指定包含文档及图片的共同上级目录，程序仅上传所选文档和匹配的引用图片。缺失或超出目录的引用会提示。浏览器单文件上传不会自动携带图片。
- **视频**：标记时间点或时间段，或选择“标注画面”后点击／拖框。发表评论前可核对时间和画面；点击已有评论可返回对应时间和区域。视频格式及编码仍取决于浏览器的播放支持。
- **匿名与删除**：名字可留空；匿名标识用于区分浏览器，不显示 IP。新发表的评论可以由同一浏览器删除，已有回复会保留；旧评论没有可验证的所有权。清除 Cookie、换浏览器或访问地址后，可能无法删除原评论。
- **智能选物**：基础标注无需模型。可选本地模型的安装、依赖、许可证与轮廓限制见 [SMART_SELECT.md](SMART_SELECT.md)；未安装相应依赖时仍可手动标注。

## 数据和访问边界

默认数据目录为 `~/.local/share/lanreview`，可通过 `--data-dir` 指定持久目录。备份时先停止服务，再整体备份数据目录；不要把临时目录当作长期备份。评审列表对允许网段内的成员开放，成员均可查看、上传和评论。

当前使用 HTTP，不提供身份核验、TLS 或多级权限。HTML 在受限 iframe 中运行，但不能保证阻止所有外部连接；只打开可信来源的 HTML，依赖外链或同目录资源的页面可能不完整。

## 开发与验证

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m unittest -v test_server test_smart_select
node --test static/tests/folder-paths.test.js
```

`test_smart_select` 是输入和资源边界测试，不证明模型推理成功；实际推理需要额外可选依赖，详见 [SMART_SELECT.md](SMART_SELECT.md)。目录测试及部分 HTML bridge 测试需要 Node.js；缺少 Node.js 时，HTML bridge 测试会跳过，目录测试无法运行。服务接口见 [API.md](API.md)，界面方向见 [DESIGN.md](DESIGN.md)。
